Responsive CSS Cheat Sheet

Filters

Change an image’s appearance: filter: grayscale(100%);

Media Queries

Apply styles at a breakpoint: @media (max-width: 700px)

Responsive Design

Use flexible grids: repeat(auto-fit, minmax(200px, 1fr))

Typography

Scale type smoothly: font-size: clamp(1rem, 2vw, 1.5rem);
