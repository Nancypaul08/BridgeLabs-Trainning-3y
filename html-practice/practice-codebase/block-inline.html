Block vs Inline Elements

Block Elements

Block elements always start on a new line and take up the full width.

This is a div — a block element used as a container.

This is a paragraph — another block element.

This is a blockquote — used for long quotations.
This is preformatted text.
    It preserves    spaces and line breaks.

Inline Elements

Inline elements do not start on a new line. They only take up as much width as needed.

This is bold text, this is italic text, this is underlined text, this is blue colored text using span, and this is a link.

div vs span

div is a block-level container — wraps large sections.

span is an inline container — wraps small pieces of text.
